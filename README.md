# Cedmod Stats

A project to display moderation staff statistics for SCP:SL servers using the Cedmod API 

| Stats Displayed |
|-----------------|
| Bans Issued     |
| Warns Issued    |
| Playtime        |
| Reports Handled |
| Reports Ignored |

---
>[!NOTE]
>This project makes use of the Cedmod API however it is not in endorsed by any of the Cedmod team
